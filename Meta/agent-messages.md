# Agent Messages

This file is the shared message board for all agents.
Agents write here to notify other agents of work that needs to be done.
Agents read here before starting work to check for pending tasks.

---

## Format

```
### [YYYY-MM-DD HH:MM] FROM → TO
**Trigger:** what caused this message
**Context:** relevant file paths or note titles
**Action needed:** what the receiving agent should do
**Priority:** low | normal | high
---
```
